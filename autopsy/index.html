Autopsy

Point it at a folder and it maps out what's actually using the space — caches, dependency folders, old installers, forgotten downloads — with a plain verdict on each: safe to delete, worth a look, or keep. It never deletes anything itself — you get the map, you make every call.

Your browser can't run this tool — it needs the File System Access API, which only Chrome and Edge support on Mac (Safari and Firefox don't have it yet). Open this page in Chrome or Edge and try again.

How this works

  1. 1
    Scan your Home folder. One grant covers Documents, Desktop, Downloads, dev projects, and the hidden Library folder — all in one shot.
  2. 2
    Also scan Applications — optional. Apps live outside your Home folder, so they need a separate grant.
  3. 3
    Get your map. Everything worth acting on gets a plain verdict. To remove something, delete it yourself in Finder — this tool only recommends, never deletes.

Runs entirely in this tab — nothing is ever uploaded. No "scan everything" button because Chrome itself blocks webpages from touching system folders like /System, a hard security rule, not a gap in this tool.

Commonly forgotten spots it specifically looks for

Reachable in Finder via Go → Go to Folder (⌘⇧G), but easy to never stumble onto otherwise:

  • iPhone/iPad backups (MobileSync) — old Finder/iTunes backups, often tens of GB.
  • Xcode device symbol files (iOS DeviceSupport) — debug data per iOS version you've plugged a device in on.
  • Docker Desktop's virtual disk (Docker.raw) — only grows as you pull container images.
  • Crash reports, logs, and window-restore state — small individually, but they pile up silently for years.
  • Safari website data (WebKit) and cookies — closer to your logins than a disposable cache, so these come back "worth a look," not "safe to delete."

One honest gap: local Time Machine snapshots (About This Mac → Storage) aren't regular files — they're APFS snapshot metadata, invisible to this or any browser tool. Only Apple's own storage panel can see those.

In the dialog that opens, press ⌘⇧G, type ~/Library, and select it — much faster than a full Home scan since it skips Documents, Photos, and everything else.
